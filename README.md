# Microshop

Projeto desenvolvido como atividade prática para estudar **Micro Frontends** com React e TypeScript.

## Sobre o projeto

O Microshop é uma aplicação web que simula uma pequena loja virtual, organizada em diferentes módulos:

- **Host:** aplicação principal responsável pela navegação.
- **Products:** módulo responsável pela listagem de produtos.
- **Cart:** módulo responsável pelo carrinho de compras.

Os módulos são carregados de forma independente utilizando `React.lazy` e `Suspense`.

## Tecnologias utilizadas

- React
- TypeScript
- React Router DOM
- CSS
- Vite

## Como executar o projeto

### 1. Clone o repositório

```bash
git clone https://github.com/SEU-USUARIO/microshop.git
```

### 2. Entre na pasta do projeto

```bash
cd microshop
```

### 3. Instale as dependências

```bash
npm install
```

### 4. Execute a aplicação

```bash
npm run dev
```

A aplicação estará disponível no endereço local indicado pelo terminal.
