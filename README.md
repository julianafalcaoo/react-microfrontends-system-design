# Microshop

Atividade desenvolvida como prática para estudar **Micro Frontends** com React e TypeScript.

## Sobre o projeto

O Microshop é uma aplicação web que simula uma pequena loja virtual, organizada em diferentes módulos:

- **Host:** aplicação principal responsável pela navegação.
- **Products:** módulo responsável pela listagem de produtos.
- **Cart:** módulo responsável pelo carrinho de compras.

Os módulos são carregados de forma independente utilizando `React.lazy` e `Suspense`.

## Tecnologias utilizadas

- React
- TypeScript
- React Router DOM
- CSS
- Vite
